# Stack segment summaries using a threshold-based test-state column

Stack segment summaries using a threshold-based test-state column

## Usage

``` r
summarize_segments_test(path_list, group_label)
```

## Arguments

- path_list:

  a list of path objects, each with a \`\$segments\` tibble.

- group_label:

  label to attach to every row (e.g. experimental group).
