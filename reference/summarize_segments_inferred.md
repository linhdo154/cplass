# Stack segment summaries from a list of CPLASS-inferred paths

Stack segment summaries from a list of CPLASS-inferred paths

## Usage

``` r
summarize_segments_inferred(path_list, group_label)
```

## Arguments

- path_list:

  a list of path objects, each with a \`\$segments\` tibble.

- group_label:

  label to attach to every row (e.g. experimental group).
