# Stack segment summaries from inferred paths (cutoff-labeled states)

Stack segment summaries from inferred paths (cutoff-labeled states)

## Usage

``` r
summarize_segments_cutoff(path_list, group_label)
```

## Arguments

- path_list:

  a list of path objects, each with a \`\$segments\` tibble.

- group_label:

  label to attach to every row (e.g. experimental group).
